# GitHub 贡献计数小抄

提交后没有立即看到贡献图更新时，可以按下面几项检查：

- 提交使用的邮箱需要关联到自己的 GitHub 账号，也可以使用账号对应的 GitHub `noreply` 邮箱。
- 提交需要位于独立仓库；只在 fork 仓库中提交不会计入个人贡献图。
- 提交需要进入仓库的默认分支，或项目站点的 `gh-pages` 分支。
- 自己拥有的仓库满足贡献规则中的仓库关系条件。
- 符合条件的提交最多可能需要 24 小时才会出现在贡献图中。

参考：[GitHub 官方排查说明](https://docs.github.com/en/account-and-profile/how-tos/contribution-settings/troubleshooting-missing-contributions) · [贡献计数规则](https://docs.github.com/en/account-and-profile/reference/profile-contributions-reference)
